# michi. — 進捗が見えるTodo

B案のグリーンの配色とダッシュボード構成を採用した、個人用Todo PWAです。
外部API、データベース、npm依存パッケージは使いません。

## 機能

- Todoの追加・編集・削除
- 完了数／目標数から進捗率を計算
- 期限・カテゴリ・次の行動・進捗メモ
- 全体の進捗（各Todoの達成率の平均）
- 進行中／完了の絞り込み、期限順の表示
- ブラウザー内への自動保存
- JSONバックアップの書き出し・読み込み
- ホーム画面への追加、初回オンライン読込後のオフライン対応

公開URL：https://todo-three-demos-1028.vastfox23.chatgpt.site

## Todo一覧を見る

ダッシュボードの濃い緑色の「TOTAL PROGRESS」をタップすると、作成済みのすべてのTodoを一覧表示します。期限・進捗率・完了数・メモを確認でき、編集・削除・進捗記録のボタンはありません。カテゴリ（未分類を含む）で絞り込み、期限が近い順・遠い順、進捗率が低い順・高い順に並び替えできます。期限なしのTodoは期限順では最後に表示します。表示条件の変更でTodoの保存内容は変わりません。「ダッシュボードに戻る」で元の画面へ戻れます。

## iPhoneで使う

公開URLをSafariで開き、必要なら公開元と同じChatGPTアカウントでサインインしてください。
共有メニューから「ホーム画面に追加」を選びます。「Webアプリとして開く」がある場合はオンにして追加してください。
追加したアイコンから開き、オンラインの状態で一度表示してから使い始めてください。

## ローカル起動

Python 3が使える環境なら、このディレクトリで次を実行します。

```sh
python -m http.server 8000
```

ブラウザーで http://localhost:8000 を開きます。
PWAはHTTPSまたはlocalhost上で利用できます。index.htmlを直接開く方法ではPWA機能は使えません。

## 確認

Node.jsで構文・基本ロジックを検証できます（npm install不要）。公開環境では、390px幅での表示、Todo追加、再読込後の保存を確認済みです。

```sh
npm run check
```

## データとバックアップ

Todoデータは各端末・ブラウザーのlocalStorageに保存されます。GitHubやサーバーには送信しません。
端末間の同期、通知機能はありません。ブラウザーのデータ削除や端末変更に備えて、定期的にバックアップを書き出してください。
Safariとホーム画面アプリの保存領域が別になる場合があるため、ホーム画面アプリから使い始めることをおすすめします。
異なるURL・ブラウザーへ移行するときは、バックアップの読み込みを利用してください。

## ファイル

- index.html：画面・スタイル
- app.js：Todo操作・保存・バックアップ
- sw.js：アプリ資産のオフラインキャッシュ
- manifest.webmanifest：PWA設定
- icon-180.png／icon-192.png／icon-512.png／icon.svg：アプリアイコン
- tests/smoke.cjs：基本ロジック確認

iPhone 14実機での最終確認は利用者側で行ってください。ホーム画面アイコンからの起動、Todoの再表示、機内モードでの起動を確認することをおすすめします。
